# Faster Corpse Cleanup

Choose how long enemy corpses stay on the battlefield through the Mod Options Menu. The timer defaults to 5 seconds and ranges from 0 to 120 seconds. Zero requests cleanup as soon as the game allows; 120 uses the original game timers.

The menu has three options:

- Enable faster corpse cleanup: turn the mod on or restore original timers.
- Corpse cleanup delay (seconds): choose your cleanup delay.
- Extra corpse cleanup: handle bodies that linger after their timers. Turn this off to use timer changes only. Some wrecks may then remain longer.

Mod Options Menu handles your saved settings. Bodies already removed cannot be restored, and long death animations can outlast the selected delay.
