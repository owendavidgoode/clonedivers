# Faster Corpse Cleanup 1.0.6

Changes since 1.0.5:

- Added support for Shared Callback Manager.
- Fixed a startup issue that could begin cleanup too early.
- Updated Mod Options Menu support for Bingus Megapack 0.2.0.
- Corrected the version shown in menu diagnostic messages.
- Kept the same cleanup options, saved settings and 5-second default.

Choose a delay from 0 to 120 seconds. Zero requests the earliest cleanup the game allows; 120 uses the original game timers. Extra corpse cleanup remains optional.

Long death animations and some wrecks can last longer than the selected delay. Co-op support remains unconfirmed.
