# Held TIE runtime build

This branch builds review artifacts only. It cannot release, merge, install a game/runtime, upload credentials, or start HD2. The job has a read-only repository token and checkout credentials are not persisted. Workflow activation is limited to `codex/tie-runtime-ci-20261110` in the named owner repository. Pushing that branch starts one 90-minute-bounded Windows2022 job; do not push before the root's independent review and explicit CI approval.

The same public HellForge commit is built baseline then patched at the same absolute checkout path. Between builds only generated `artifacts`, `bin` and `obj` directories inside the verified dedicated checkout are removed. Tool/download caches are reused; source modifications are restricted to the pinned three-file patch. No MSVC/SDK installation runs: NativeAOT uses the hosted image's existing Visual Studio. The exact .NET10.0.403 SDK is extracted privately after official SHA512 verification.

Both Steamworks1.55 inputs come from immutable public mirror commit1263fbb403ca89f11cdf33860b565538e0836f6c and must match the independently established original hashes. No local game file, archive history, account file or private SDK input is uploaded. The build-input directory is never an artifact path. Upstream's shims and bridge are generated from those inputs, as its official build expects.

Each variant must pass upstream source tests, the complete native engine build/smokes/NativeAOT build, and official app packaging. No warning/audit/test suppression is used. PowerShell5 child processes have separate OS stdout/stderr streams; the official WFP usage smoke's expected exit2 must not become a wrapper error. Errors thrown by upstream fail the stage. The observed local symlink privilege failure must pass on this host or the run remains incomplete.

The verifier checks engine manifests and every hash, shim receipts, complete app payload and payload ZIP, actual compiled179/180-row catalogue, unchanged179-row prefix, same build path, and baseline/patched file inventory parity. The raw original Steam DLL/SDK hashes are forbidden from the payload. It reports every binary/hash difference for later review rather than declaring release equivalence. Only explicitly copied complete engineZIP/payloadZIP/setupEXE files plus build/version/verification logs enter `artifact-publish`; no cache/source/private-input directory is uploaded. Partial failure logs may be retained, but failed runs are not complete packages or deployment approval.

Expected duration:30–60minutes for both variants,90minute job timeout. Estimated retained artifacts can exceed1GB because both complete app payloads and setup executables are intentionally retained for parity review. Retention14days. No installer signing is configured. No baseline or patched executable is installed on the user's machine by this workflow.

Offline tests: `python -B -m unittest discover -s tools/tie-runtime-ci -v`. `build.ps1` without `-Run` is inert. Root must review the exact commit/diff before push. After CI, download artifacts into a new isolated folder, recheck receipts and complete differences, and seek the separate release owner's decision; no automatic follow-on deployment exists.
