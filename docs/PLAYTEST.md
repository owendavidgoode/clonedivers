# Existing-release multiplayer check

Use installed launcher **1.4.1 / r8**; this check requires no new release. It needs two
players and is still pending. Use English game audio/text, Brawny body type, and select
a specific voice rather than Random. [Equipment requirements](TEAM-SETUP.md).

1. Both players select Commandodivers with the game closed, then join a private mission.
2. Rotate voice slots 1–4 (Sev, Fixer, Scorch, Boss). For each slot, both the speaker
   and listener check an affirmative, negative, follow/hold ping, reload and grenade call.
   Record the actual character heard and the exact trigger for any mismatch. Some calls
   and shared exertions intentionally retain clone recordings.
3. Check the four B-01 helmet variants and their corresponding unlocked bodies. Record
   the item code and body type for any incorrect model. Shared-model side effects are
   documented in the team guide.
4. Reinforce once. Confirm the chosen voice remains the one the listener hears. Swap
   armor while keeping the same voice slot to confirm that voice selection is independent.
5. Close the game, select Clonedivers, and relaunch. Check the ordinary clone opening,
   clone voices and armor. Scope removal should remain active. Then close the game and
   select Helldivers; check that the original game presentation returns.
6. In a modded mode, confirm the floating sights are gone, the reticle still works,
   and the existing Spear/Wasp exceptions remain usable.
