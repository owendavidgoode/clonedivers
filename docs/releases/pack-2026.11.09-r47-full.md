# EmpireDivers Forge r47 Full

Empire uses Full textures and fixed CIS enemy models on HellForge game build 25480438. It adds Stormtrooper SEAF appearances and three Imperial Clone Veteran sets based on late-war Phase II armor. It restores native Foesmasher cape geometry, preserves the hidden Gilded Quill and gives the Spear a red trail.

The Full catalog contains 96 assets. Lighter and alternate CIS variants are held. Clones, Commandos, Regular and the existing gameplay preset keep their published routing. The release scope excludes experimental TIE, compact LEGO and Yoda, Mixed Factions and Chaos features.
