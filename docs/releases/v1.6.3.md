# Clonedivers 1.6.3

Launcher **1.6.3** with pack **2026.09.25-r14**. The launcher itself is unchanged apart from
its version. Accept the launcher update, then choose **Update pack**. Nothing new is
downloaded; the marker files are simply set aside.

- **Spider Droid aim markers removed.** They didn't look right in game. Spider Droids are back
  to the plain CIS model.

Everything else is unchanged from 1.6.2: the Venator fleet opening, the voice gap fill and
the "Boss/Clone" voice. HD2 build 25480438 (7.1.1).
