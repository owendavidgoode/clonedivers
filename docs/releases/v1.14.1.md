# Clonedivers 1.14.1

A cleaner launcher and updates that survive a flaky GitHub.

- **One obvious button.** Each state has a single primary action (Set up, Install mods, Sync account, Launch, End session, Update). Maintenance actions moved into "More options".
- **Options where they apply.** Clones retains its appearance choices and Full | Lighter texture switch. Empire retains the published r45-v4 Full appearance with fixed enemy models. Regular shows no appearance controls. Experimental Empire Lighter and enemy switches are not included.
- **Saved choices stay readable.** Existing preferences and public Empire receipts are preserved. If saved appearance options are unavailable in Empire, choose **Use published Empire appearance** explicitly or return to Clones to use those choices. Switching modes alone does not rewrite them.
- **Plain-language status.** Errors read as one headline and one sentence; the technical detail stays in Session details.
- **Updates that work.** "Update available" is now the main button, with a progress bar and clear success or failure. Launcher, pack and mod downloads retry server errors for several minutes and fall back to a cache-busting address when GitHub serves a stuck error for a file (seen on November 9). Every download is still size- and SHA-256-verified.

Game data, account and mod settings are unchanged by the update.

Clones/Commandos r19 and the gameplay preset are unchanged. This release does not
include r47 appearance changes or repair the LEGO trooper proportions. Linux
gameplay and multiplayer remain unqualified. The known native-quit issue remains;
use **End session** for the supported cleanup flow.
