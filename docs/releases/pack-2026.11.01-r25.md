# Pack 2026.11.01-r25 — HD2 7.2.2 audio compatibility

Targets Steam build **26251122**, with all five installed depot identities.
The Windows launcher remains **1.7.3**. The shared profile feeds support both
Windows and the Linux launcher; Linux GUI development remains independent.

With HD2 closed, choose **Update pack** in the launcher. Existing unchanged
downloads are reused. The update applies to Clonedivers, Commandodivers and
EmpireDivers, Full and Lighter textures, with either optional enemy replacement.

Old sound-bank overrides omitted current HD2 event objects, including weapon
events. This update rebuilds their routing and dependencies from current native
data while retaining replacement media by stable identity. It restores 246
distinct missing native event IDs across 267 bank-variant occurrences; the
Super Earth weapon bank accounts for 13 distinct restored events. These counts
include ship, voice and UI events and are not counts of weapons.

The repair also aligns source codec declarations with effective replacement WEM
data, rebases stream wrappers, preserves two recordings moved to native streamed
identities, refreshes 35 English text variants with current game entries, and
corrects the Clone intro's declared Bink extent without changing its video.
All unrelated resource payloads and original mode/option/profile gates remain
intact. This public repair starts from r24 and does not promote private Empire
armor, crew, vehicle or voice experiments.

The old Lua runtime archives are excluded: the direct shared loader still names
Steam build 25480438, and HD2Runtime 0.50.1 says its direct-game implementation is
unchanged from 0.40.1; its new support is for HellForge. Script-dependent camera,
menu, aircraft switching and LEGO death features therefore remain unavailable
in this compatibility pack. Static models, effects and replacement audio remain.

Offline acceptance covers all **96 production selections / 16 distinct file
sets**: 6,544 archive contexts, 1,960 native bank contexts, 82,232 selected stream
wrappers, 1,936 dependencies, 200 text-table contexts and 698,496 available PCM
or Vorbis source checks, with zero faults. Repeated cases across configurations
are included in these counts. The 107,168 unresolved source cases are unchanged
from native and may resolve across banks; they are not diagnosed as silence.
Windows native tests, 36 Linux checks and four focused bank regressions pass.

**No new audible gameplay acceptance is claimed.** The active Empire development
installation, its private feed and the Linux GUI worktree were not changed.
Player acceptance should fire/reload R-40 Sightliner, P-44 Mist, AMW-20 Apex and
LAS-44 Nova, then compare an existing replacement blaster and both voice modes.
Availability of equipment depends on each player's unlocks.
