# EmpireDivers battle intro and update detection

Launcher **1.7.1**, pack **2026.09.27-r17**. Update the launcher first, then
choose **Update pack** with the game closed.

EmpireDivers now opens with **Helldivers vs Star Wars**, a 38-second battle
sequence with its matching soundtrack. The trailing black is trimmed and the
startup logo videos are replaced by brief silent frames. **Clonedivers keeps
its existing Venator intro**, byte for byte.

The third launcher option, Covenant toggle, and SAI E-11 firing sounds and blue
blaster bolts remain included. Empire's extra intro download is about 49.7 MB;
Clonedivers' selected pack files are unchanged.

Older launchers now receive a compatible update feed so they can discover
1.7.1. The new launcher checks again while left open, and retains app upgrade
metadata when it has to fall back to a saved profile pack.

Video: [ChrisMastree Productions — Helldivers vs Star Wars](https://www.youtube.com/watch?v=c8bCzPS9DMI).
The source credits DaricShireMusic for the music and describes the sequence as
clips made for HaloFollower's ODST vs Helldiver Episode 9. These credits remain
here after removing the startup cards. The Clonedivers Venator credits remain
in the earlier release notes.

Validation: all 912 battle-video frames and both blank-logo frames decode with
the installed game's Bink library in an offline process; Wwise PCM soundtrack
decodes at 48 kHz stereo. Sixteen mode/profile/Covenant/droid combinations verify
Empire-only selection, unchanged Venator/SAI assets and gap-free patch numbering.
The original 1.6.3 parser accepts the compatibility feed and offers 1.7.1.
Native launcher tests and coordinated publication tests pass. This is not a
gameplay test; the existing Empire/Covenant limitations still apply.

Rebuild: `tools/build-battle-intro.py`; assets use four-slice Bink 2 (`/V6344`).
The current English cutscene bank changes only the intro source codec. The logo
bank retains event routing and substitutes silent PCM media. Source identities
and asset hashes are recorded in [the build receipt](pack-2026.09.27-r17-build.json).
