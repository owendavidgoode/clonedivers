# Pack 2026.10.09-r24 - startup archive repairs

This release repairs two native archive layouts while retaining the full models,
audio, variants and runtime features. Launcher 1.7.3 is unchanged.

- Constitution audio MAIN: append 52 zero bytes to the existing 204-byte archive;
  its wrapper, metadata and audible STREAM remain exact.
- Star Destroyer MAIN: order resource rows by type then name, with dense ordinals.
  Only 132 file-table bytes change; all six resources, offsets and companions remain exact.
- Eagle and LEGO Yoda: rebind the existing context pack version to r24. Each addon
  changes exactly two bytes; every other module and native behavior remains exact.

The repaired full r23 selections reached the solo ship through the desktop launcher:
Clone/Full with 1,199 files and Empire/Full with 1,396 files. Imperial armor and Star
Destroyer silhouettes were observed. No new native crash dump or DirectStorage log
appeared in those checks. These startup observations do not establish in-mission
sound, death playback, vehicle physics or complete visual acceptance. Final r24
Clone and Empire selections also reached the solo ship through the desktop
launcher with no new dump or DirectStorage error. Installed Eagle/Yoda
context checks pass; Empire logs show Yoda armed and Eagle comparison applied.

The r24 candidate preserves all 1,809 logical rows. Actual bundled launcher 1.7.3
qualification covers all 96 mode/profile/option states and 16 effective file sets;
only the four intended MAIN identities change. The archive preflight checks
contiguous type ranges, minimum MAIN/metadata padding and safe resource extents.
It accepts legacy ordinals and within-type name order; the corrected ship builder
separately asserts its new dense ordinals and type/name ordering.

Update to the new pack version before using Check/Repair. Equal-version r23 repair
reconstructs the old saved receipt and could restore the defective files; after a
successful r24 update, Check/Repair uses the corrected receipt. The r24 assets and
all three feeds are published and independently verified. Actual launcher Check/Repair
retains all 1,396 corrected Empire files, and its subsequent launch reaches the ship.
