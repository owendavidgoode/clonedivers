# Clonedivers 2.0.2

> **Live release:** Windows `v2.0.2` is live as GitHub `Latest` (`Clonedivers.exe` `76,368,366` B, SHA-256 `a7150afd90cb6f76c3187b261c478dbc3d858b1688d3f24f1ca4f755d814042f`) and active in root public `"app"` feeds (`manifest.json`, `manifest-v3.json`, `manifest-v3-current.json`) alongside [Linux Forge `0.9.2`](https://github.com/owendavidgoode/clonedivers/releases/tag/linux-v0.9.2) and [`forge-mods-2026-11-21`](https://github.com/owendavidgoode/clonedivers/releases/tag/forge-mods-2026-11-21).

## Highlights

- **Unified Avalonia 11 Launcher UI (PR #32):** Single-window modern dark Star Wars interface shared across Windows and Linux (`--steam` and `--classic` fallbacks retained). Cuts home clutter from 24 to 7 top-level controls, adds a slide-over Customize drawer with live pre-click cache/download-size preview, a non-blocking update banner, an in-window 4-stage Guided Setup (multi-drive free-space picker, fixed non-jumping Steam Guard QR card, live auto-advancing 5-step Account Sync tracker, and pre-download High / Balanced / Low VRAM 512px texture selection), and Settings/Diagnostics with Copy & Save Support Report.
- **Structured Progress Engine (`OperationProgress`):** Real file counts, bytes, MB/s, ETA, `Power.KeepAwake`, Windows taskbar progress (`ITaskbarList3`), and 100ms throttling across gameplay mod installs, pack planning/export/backup/import/verify, and HellForge `0.3 -> 0.4` upgrades.
- **Difficulty 11 FPS Fix (`build25480438-r7`, PR #31):** Upgrades `clonedivers.lego-compact-leaf-writer` (`0.2.1`, `254,245` B, SHA-256 `f41439f3...`) and `clonedivers.empire-atst-writer` (`0.2.1`, `36,187` B, SHA-256 `73499324...`), eliminating D11 leaf-writer FPS collapse (`-34.25%` -> `+4.02%` across 12 live D11 runs + 15-min `S4` soak at `86.09 FPS`). Existing installs auto-upgrade enabled `0.1.0`/`0.2.0` writers.
- **Account Sync & Wave B Fixes (PR #30, PR #32):** Fixes Issue #28 (`autoApply` loop, startup shim probes, duplicate manager windows), prunes completed backups after interrupted pack recovery, and enforces exact download-size consent matching on Step 4 retries.
