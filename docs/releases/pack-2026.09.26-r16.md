# LAS-12 SAI sound and blue blaster bolts

Pack **2026.09.26-r16** for launcher **1.7.0**. Close Helldivers 2 and choose
**Update pack**. The additional download is 2.27 MB; existing downloads are reused.

The LAS-12 SAI now fires with **E-11 sound** and **Battlefront-style blue blaster
bolts** in both Clonedivers and EmpireDivers, with either texture profile and
Covenant on or off. Its gun model stays unchanged.

Audio: [Bullet177013's LAS-12 E-11 sound](https://www.nexusmods.com/helldivers2/mods/16485?tab=files&file_id=66060).
Bolts: thebf333's Custom Projectiles blue bolt, already shipped in the pack,
mapped to the SAI's distinct projectile effect. This closes a gap in the older
laser effects pack, which did not replace the SAI's new effect resource.

Offline validation: the source preserves current audio routing and dependencies;
42 media references use the E-11 sample, which decodes successfully. The bolt
payload matches the shipped blue bolt and uses current particle format 115.
No existing resource collisions; 16 mode/profile/toggle combinations retain all
previous content and add exactly the SAI bundle. Native tests and profile file
hash checks are required by staging. **Gameplay remains unverified**, as authorized
for this release. The EmpireDivers and Covenant limitations in the
[1.7.0 notes](v1.7.0.md) still apply.

Rebuild: `tools/build-sai-release.py`. Source pins and mapping evidence:
[build receipt](pack-2026.09.26-r16-build.json),
[offline checks](pack-2026.09.26-r16-offline.json).
