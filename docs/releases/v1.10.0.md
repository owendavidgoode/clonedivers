# Clonedivers 1.10.0 — Forge replaces the Steam launcher

Existing Windows launchers receive this through their normal update button.
The default application now runs Regular, Clones and Empire in a separate
HellForge installation. Use default Steam to play official online HD2.

The updater preserves a verified previous executable for rollback, carries
available old appearance preferences into first-time Forge setup, and keeps
existing Forge preferences authoritative. It does not reset accounts, import a
stale capture, change mod options or edit live Steam game files. New Forge update
checks require the Forge channel and verify the versioned EXE's size and SHA256.

Read [migration and first setup](https://github.com/owendavidgoode/clonedivers/blob/main/docs/FORGE-MIGRATION.md).
HellForge0.3.0-beta/engine0.1.41/SDK15/game25480438, supported isolation/sandbox,
your own HD2 account and permitted matching gameplay mods are required. Updating
the launcher does not install these dependencies. Private Heavy/Squad repairs
are not distributed; new-peer onboarding remains open. Progress imports only
HD2 → Forge; Forge rewards do not count back in official HD2.

The official Steam installation may still contain your previously enabled mods.
Follow the guide's one-time manual cleanup; this updater does not remove them.
Keep the prior executable/package for recovery. Normal gameplay is Forge;
explicit --steam remains a recovery tool.

Windows source/session checks, isolated bridge/process/account fixtures and Linux
package checks are separate from gameplay acceptance. Actual separate-PC
multiplayer, Linux account/Proton gameplay and mission reward persistence remain
unverified. Native Quit and ship distortion remain open; use End session for
official cleanup. No engine or security setting is changed by this release.

The single EXE supports in-place updates. The optional Windows ZIP also includes
the setup guide and runtime/PresentMon licenses. GitHub asset digests and the
published update feeds identify the exact uploaded executable.
