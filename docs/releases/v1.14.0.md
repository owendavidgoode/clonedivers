# Clonedivers 1.14.0

- Quitting from HellForge uses the new clean-exit fix. End session also handles
  completed cleanup and bridge timeouts correctly.
- Owned premium Warbonds open after a verified account import. Existing Forge
  progress carries forward when you sync your HD2 account.
- Guided game setup copies an existing game or downloads through Steam with a QR
  approval in the launcher. Setup repairs missing preset requirements.
- Empire mode prepares EmpireDivers r45-v4 for game build 25480438. It includes
  expanded Imperial armor, vehicles, ships, names and voices, with the cape repair
  tested across three D11 drops and clean quits.
- Empire uses Full textures with CIS droids and walker weapons enabled, Covenant
  disabled. Clones keeps its existing r19 content and saved appearance choices.
  Prepare Empire once after updating. Its download is approximately 8.44 GB.
- Interrupted appearance downloads reuse verified files. Updates retain the
  previous executable, and account refresh and session diagnostics recover cleanly.

Requires HellForge 0.4.0-beta, engine 0.1.47 and game 25480438. Gameplay preset
catalog r3 includes clean-exit 0.2.0. Separate-PC multiplayer and Linux gameplay
still await acceptance. Camera pullback, per-attack TIE switching and LEGO Yoda
death routing remain pending.
