# Clonedivers Forge Linux 0.8.1

The Forge desktop has a clearer primary action, consistent mode views, improved
connection and recovery messages, and diagnostics under More options. Verified
downloads resume and retry temporary failures while retaining size and SHA-256 checks.

Empire retains the published r45-v4 Full appearance with fixed enemy models.
Clones/Commandos r19, its texture and optional-skin choices, and the gameplay preset
are unchanged. Experimental Empire Lighter and enemy switches are not included.
Saved unavailable choices remain readable; use **Use published Empire appearance**
explicitly or return to Clones to use them. Existing public Empire receipts remain
compatible, and switching modes alone does not erase saved choices.

Keep the launcher and its companion bridge together when upgrading the portable
package, or install the new .deb over the previous package. Forge remains the
default entry point; `--steam` opens the existing Steam workflow. Linux updates
still open the compatible release page rather than replacing the package in place.

This release does not include r47 appearance changes or a LEGO proportion fix.
Linux gameplay and multiplayer remain unqualified. The known native-quit issue
remains; use **End session** for the supported cleanup flow.
