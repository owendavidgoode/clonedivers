# Clonedivers 1.4.1

Scope removal is now automatic in **Clonedivers** and **Commandodivers**. The
Hide weapon sights toggle is gone; **Lighter textures** remains available.
Helldivers mode restores the original game by parking the mods.

Update the launcher and pack to **2026.09.12-r8** with the game closed. Previously
turning scope removal off no longer excludes the fix. If it was already on, the
pack update reuses the installed files without downloading replacement assets.
The reticle and the existing Spear/Wasp scope exceptions are unchanged.
