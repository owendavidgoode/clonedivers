**How to update:** download **Clonedivers.exe** below and replace your old one. Your game folder, installed pack and ON/OFF state carry over.

Windows will say "Windows protected your PC" again because the exe changed: **More info → Run anyway**.

**New in 1.2.0 — the look**
- Dark title bar: the window is one navy surface (Windows 11 paints it in the app's colour; Windows 10 goes dark).
- The clone helmet from the icon sits in the header next to the name, drawn as vectors so it is crisp at any scaling.
- Rounded buttons with real hover, press and keyboard-focus states; LAUNCH text is navy on orange so it is readable.
- The game-folder line fits on one line and says **Found via Steam:** when it found the game by itself; **Open** sits next to **Change…**.
- Under the big switch: one bright status line and a dim hint instead of a grey paragraph. Nothing was removed.
- Download and install: one thin blue bar for the whole 9.5 GB, then one for the install, with the percentage in the window title, so the taskbar shows progress while you alt-tab. Your PC stays awake while it runs.
- A small dot on the big switch: filled blue when clones are ON, hollow when OFF, amber while the game is running.
- The pack button now reads **Download pack**, **Update pack** or **Pack up to date**, with the version and size underneath. If GitHub could not be reached it says so and retries by itself (or click it).
- The switch reads **INSTALLING PACK…** while a pack installs instead of flipping ON/OFF half-way.
- The footer version comes from the build itself: v1.2.0.

**Unchanged** — the big CLONES: ON / OFF switch, Launch via Steam, resumable hash-checked download, install from zip, refuses to touch anything while the game runs, never touches the game process.

**Pack** — this build offers pack `2026.09.05-r3`: 9.5 GB in five parts (shows as 8.8 GB in the app), built for Helldivers 2 patch 7.0.2. Temuera Morrison's clone voice now covers the Democracy Officer and Mission Control. Already on r3? Nothing to download.
