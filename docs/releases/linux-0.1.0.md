Native Linux terminal launcher preview for Clonedivers.

- Choose Clonedivers, EmpireDivers or vanilla Helldivers.
- Reuse the public pack feed, verified/resumable downloads and cached mode changes.
- Discover native/Flatpak Steam and external libraries, or choose the game folder.
- Repair installed content and recover interrupted updates.
- Detect the game under Proton and prepare FPV defaults inside its Proton profile.

Download **Clonedivers-linux-x64.tar.gz** for a typical Linux PC or Steam Deck.
Extract it, open a terminal in that folder, then run `./clonedivers` (use
`chmod +x clonedivers` if necessary). No separate .NET runtime is required.
The arm64 package is a launcher build, not a claim of ARM game compatibility.

[Setup and commands](https://github.com/owendavidgoode/clonedivers/blob/codex/linux-launcher/docs/LINUX.md).

Automated Linux checks verify installation, downloads, switching and recovery.
Actual Steam/Proton gameplay with the pack remains unverified. Windows performance
sharing and launcher self-update are not included in this preview.
