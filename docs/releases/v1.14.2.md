## Storage, Setup, and Download Fixes (Wave 1)

- **Reuse completed pack backups when switching selections:** `HellForgePack.PlanAsync`
  scans `CacheRoot\backups` for `applied` or `restored` `previous-pack` folders
  alongside `exports\`, so toggling Clones `Full`/`Lighter` or appearance options
  reuses local verified bytes without re-downloading.
- **Scoped pruning and atomic export receipts:** `HellForgeClient.PrunePackStorage`
  now aborts globally only for the active installation's own pending/mismatched
  `PackIntent` or `InterruptedGameplayProblem`; records from other roots preserve
  their referenced backups without halting pruning, non-terminal or unreadable
  `outcome.json` backups stay protected, `SupersededExports` skips individual
  unreadable receipts cleanly, and `ExportFilesAsync` writes `clonedivers-export.json`
  atomically via `.tmp`, disk flush, and `File.Move`.
- **Resumable folder deletion:** `HellForgePack.DeleteStorageFolder` renames
  pruned folders to `deleting-<name>`, deletes `previous-pack` and payload files
  before `outcome.json` / `clonedivers-export.json` markers so partial deletes stay
  retryable, and retries leftover `deleting-*` folders on later prunes.
- **Cross-target installer cache migration:** `HellForgeSetup.InstallAsync` (and
  `UpdateAsync`) reuses, moves, or cross-volume copies verified `HellForge-Setup.exe`
  files from `%LOCALAPPDATA%\Clonedivers\installers`, `%USERPROFILE%\HellForge`, and
  the remembered `last-install-cache.txt` path into `Clonedivers-HellForge-cache\installers`.
- **70 GB setup budget and resumable downloads:** `HellForgeSetup.cs` and
  `HellForgeGameSetup.cs` require `70 GB` (`70 GiB`) free on the Forge drive (naming
  the drive in errors), check installer cache volume capacity, resume partial
  appearance downloads as `.partial` files in `appearance-downloads` via HTTP Range,
  and report cumulative export byte progress.

## Windows Launcher and Warbond Fixes (Wave 1)

- **Sticky operation failures:** `HellForgeForm` preserves interactive
  `operationFailure` messages across 5-second background refresh transitions until
  the user clears or retries the action.
- **Deferred Warbond opening and retry:** `HellForgeWarbonds.ManagerWindowOpen`
  detects `HellForge` and `HellForge.Launcher`. If opening owned Warbonds is deferred
  after account import while HellForge is open, the launcher guides the player to
  close HellForge, retries automatically once the window exits, and blocks launching
  until pending Warbonds are unlocked.
- **Marker-only missing-installation detection:** `InstallationMissing` returns `true`
  only when the root folder or `hellforge-install.json` is missing (while preserving
  `UpgradeProblem` recovery). Installations missing `HellForge.Cli.exe` /
  `HellForge.exe` show `"Repair HellForge with the official installer, or Locate another folder"`
  with **Locate Forge** instead of offering a second fresh install.
- **Steam vs capture-block button alignment:** `launch.Click` checks `!SteamReadyCheck()`
  before `captureBlock`, matching the displayed `OPEN STEAM` / `OPEN HELLFORGE` state.
- **Completion and startup notices stay visible:** `OperationAsync` clears `headline = null`
  so post-operation success text survives transitions to `Ready to launch`, and
  `startupNotice` stays preserved past `"Checking HellForge…"`.
- **Focused account-sync instructions:** Splits `SyncInstructions` (Steam requirement,
  admin approval for sync proxy, `Profile > Account sync > Sync Inventory`, closing
  HellForge after HD2 exits, leaving `Apply import` and `auto-apply` off) from
  wizard-only `SetupRequirements` (`70 GB`, QR/fallback, 2–3 admin prompts).
- **Unreadable `hosts` handling:** `captureBlockUnreadable` routes `IOException` /
  `UnauthorizedAccessException` reading `hosts` to **Session details** instead of
  misleading `OPEN HELLFORGE` sync cleanup guidance.
- **Restore minimized HellForge window:** `StartOrActivateManager` uses
  `MainWindowHandle` with `IsIconic` / `ShowWindow(SW_RESTORE)` / `SetForegroundWindow`
  (plus `AppActivate` fallback) so `OPEN HELLFORGE` and `SYNC HD2 ACCOUNT` restore a
  minimized window instead of doing nothing or spawning a duplicate.
- **Network error precedence:** `FailureSummary` matches `HttpRequestException`,
  `SocketException`, `"No such host"`, and `"access a socket"` before `"denied"` /
  `"permission"` so blocked sockets report connection errors rather than folder permissions.
- **Additional Windows resilience:** Manual update-check timeouts surface a retry
  message without background checks overwriting `failureDetail`, missing saved Forge
  folders no longer block self-update, and idle status text is no longer duplicated
  below action buttons.
