# Clonedivers Linux 0.8.0

- Guided Forge game setup and recovery handle empty or invalid saved installation
  folders and incomplete game copies.
- Owned premium Warbonds open after verified account import and idle review.
- End session and closing recover from bridge faults and timeouts. A persistent
  Steam relay host allows setup and launch to continue.
- Empire mode prepares EmpireDivers r45-v4 for build 25480438 with Full textures,
  CIS droids and walker weapons enabled, Covenant disabled. Clones retains r19 and
  saved appearance choices. The Empire download is approximately 8.44 GB.
- Appearance preparation reuses verified exports. Failed mode switches preserve
  the requested selection, and unavailable update checks recover cleanly.

Install the x86-64 .deb or extract the complete portable archive, including forge/.
The Forge channel marker is required for update notices. HellForge 0.4.0-beta,
engine 0.1.47 and game 25480438 are the supported runtime. The pinned gameplay
preset includes clean-exit 0.2.0.

Windows Empire r45-v4 passed three D11 drops with clean quits. Linux gameplay,
Proton/account integration and separate-PC multiplayer still await acceptance.
Camera pullback, per-attack TIE switching and LEGO Yoda death routing remain pending.
