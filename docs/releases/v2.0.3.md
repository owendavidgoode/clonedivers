# Clonedivers 2.0.3

> **Live release:** Windows `v2.0.3` is live as GitHub `Latest` (`Clonedivers.exe` `76,466,670` B, SHA-256 `2514ba2e7e5a8a6e2eaec15c02ca6a6a898aa94a37b983bcb8186144382c27c0`) and active in root public `"app"` feeds (`manifest.json`, `manifest-v3.json`, `manifest-v3-current.json`) alongside [Linux Forge `0.9.3`](https://github.com/owendavidgoode/clonedivers/releases/tag/linux-v0.9.3).

## Highlights

- **Radically Simplified Defaults & 1-Click Flow (PR #33):** New installs default straight into the full-variety Star Wars mix with granular overrides tucked cleanly under a collapsed **Advanced** drawer, 1-click **Apply & Download / Apply Now** right inside Customize, 1-click **`UPDATE & LAUNCH`** for installed players, and clear **`Resume Download (X left · Y saved)`** status across restarts.
- **Auto Hardware Performance Presets & Step-Down Safety Net:** Scans GPU VRAM and system RAM to recommend the best preset across the expandable 5-tier ladder (`Ultra` → `High` → `Balanced` → `Low VRAM 512px` → `Ultra Potato`), and automatically offers a 1-click tier step-down after a VRAM crash or low-FPS session.
- **Star Wars Polish, Audio & Squad Tools:** Adds holoterminal faction accents, hover transitions, dark scrollbars, procedural Star Wars UI sound effects (with header mute toggle), understated faction-aware tactical status lines, clickable short **What's New** release notes on the update banner, system tray icon + optional minimize-to-tray, Discord Rich Presence IPC, subtle `r7-xxxx` Squad Match Code in the footer, and optional 1-click Start Menu & Desktop self-install when run from `Downloads`.
- **Diagnostics, Auto-Clean & Operations:** Adds 1-click **Verify & Repair**, Disk Usage breakdown + safe cache cleaner (plus background stale-cache cleanup), plain-English Crash Triage with automatic session/crash reporting to `clonedivers-telemetry.goodecraft.com`, Host Gameplay Controls (`Chaos Invasions`, `Heavy SEAF`, `Faster Corpse Cleanup`) under Advanced, `Esc`/`Enter` modal hotkeys, cross-platform embedded `Window.Icon`, visible UI error toast, conditional Windows SmartScreen signing CI hook, and a nightly upstream-link health check workflow.
