**How to update:** download **Clonedivers.exe** below and replace your old one. Your game folder, installed pack and ON/OFF state carry over. This is the last time you do this by hand: from 1.3 on, Clonedivers updates itself.

Windows will say "Windows protected your PC" again because the exe changed: **More info → Run anyway**.

**New in 1.3.0 — small updates**
- **Update pack** now downloads only the files that changed. Everything you already have is kept and renamed in place, so a new pack is usually a few hundred MB instead of 9 GB. The first time the new app checks your files it reads them once (a minute or two on a hard drive).
- **Pack up to date** turned into a repair button: click it to check every installed file and re-download only what is missing or damaged.
- If an update is interrupted (power cut, antivirus holding a file), the switch reads **UPDATE INTERRUPTED** and a **Finish update** button completes it in seconds, without internet.
- **Optional groups.** When the pack carries an optional extra (the Republic Commando squad is first in line), it shows up as a toggle under the pack buttons. Off parks its files; on downloads just that group. The rest is renumbered so nothing goes missing.
- **Clonedivers updates itself.** When a new version is out, a line under the pack buttons says so. One click downloads it and restarts the app.
- **Game-update warning.** Clonedivers now knows which Helldivers 2 build the pack was built for. When Steam has updated the game (or has an update queued, or Owen has marked the pack broken), the status line says so and **LAUNCH** asks whether to switch the clones OFF first. Say Yes until Owen confirms the pack on the new patch.

**Unchanged** — the big CLONES: ON / OFF switch, Launch via Steam, install from zip, refuses to touch anything while the game runs, never touches the game process.

**Pack** — this build offers pack `2026.09.05-r3`, the same content as before (Temuera Morrison's clone voice for the Democracy Officer and Mission Control included), now published file by file. Already on r3? The first click just verifies your files and downloads nothing.
