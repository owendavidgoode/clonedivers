# Clonedivers 2.2.2

> **Release (`v2.2.2`):** Pairs with [Linux Forge `0.11.2`](linux-v0.11.2.md), upgrading the gameplay catalog to **`build25480438-r15`** (`18` verified archives, `8,568,853` B, `0` `hf-mod.com` URLs, Squad Match Code `r15-a05a`) alongside **EmpireDivers `2026.11.27-r54`** and **Clonedivers `2026.11.27-r25`**. Names Difficulty 12 **`LEVEL 12: STORMTROOPER`** in **EmpireDivers** (while keeping **`LEVEL 12: CLONE WARS`** in **Clonedivers**) both in-game (`clonedivers.chaos-invasions 0.5.1`) and across the launcher UI, and turns **every Star Wars & host gameplay goodie ON by default** (`Encrypted Death Trooper Voice`, `Total War` Chaos Invasions, `Constant` Heavy SEAF Reinforcements, `Faster Corpse Cleanup`, `Difficulty 12` Theater Scale, `Delta Squad`, `80/20 Mixed Bots + CIS Droids`, `Mixed Covenant + Squids`, and all `9` optional companion/gameplay code mods).

## Highlights

- **Difficulty 12 Named `LEVEL 12: STORMTROOPER` on EmpireDivers** — Galactic War Difficulty 12 displays **`LEVEL 12: STORMTROOPER`** in-game and **`Stormtrooper`** across launcher badges, Customize controls, and Discord diagnostics when playing EmpireDivers, while Clonedivers keeps **`LEVEL 12: CLONE WARS`**.
- **All Launcher Goodies Enabled by Default** — Fresh installs and pre-`v2.2.2` upgrades turn on **Encrypted Death Trooper Voice** (slot 4 in Empire), **Total War** Chaos Invasions, **Constant** Heavy SEAF Reinforcements, **Faster Corpse Cleanup**, **Difficulty 12** Theater Scale, **Delta Squad**, **80/20 Mixed Bots + CIS Droids**, **Mixed Covenant + Squids**, and all **9 optional SDK-16 code mods** (`HostTheaterDefaultVersion = 3` one-time migration preserving explicit `v2.2.2+` opt-outs).
- **Full `D1–11` Intensity Preserved Alongside `D12` Theater** — `HostMutatorConfig.BuildOptions` now preserves `"total-war"` Chaos and `"constant"` / `"heavy"` SEAF waves on Difficulties `1–11` even while `Difficulty 12` (`"clone-wars"`) is armed, instead of collapsing `D1–11` back to standard pacing.
- **`build25480438-r15` Auto-Upgrade (`r15-a05a`)** — Automatically upgrades enabled `clonedivers.chaos-invasions 0.5.0 -> 0.5.1` (`82,166` B, SHA-256 `5cc71e43a04cde1b5ab1a56a5532b15372a6872ded80a4e0f3d3ac8775931d18`, ContentHash `3d2fc0f17d881f2077f54b670d6d752c0fb2995b5666435b7163a9b44e3852b8`) from [`forge-mods-2026-11-27`](https://github.com/owendavidgoode/clonedivers/releases/tag/forge-mods-2026-11-27).
