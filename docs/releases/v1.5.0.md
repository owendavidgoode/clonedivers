# Clonedivers 1.5.0

Choose your universe and texture profile before downloading. Switching between
already-downloaded modes no longer needs a confirmation dialog.

- Commandodivers now explains the Brawny body-type requirement.
- Full and Lighter textures are separate choices available before installation.
- Check and repair preserves the selected universe. Interrupted updates resume the
  requested mode and texture profile, including when more files are needed.
- Previously cached modes remain available offline when their files are present.
- Profile switches retain reusable files and unfinished downloads. Stalled downloads
  retry and resume automatically before offering another attempt.
- Help & diagnostics provides a previewable support report with hardware, versions,
  installation state and recent operation results. Nothing is uploaded automatically.
- Pack r9 introduces independent Full/Lighter profile selection while retaining the existing tested game assets.

The launcher update preserves existing Full/Lighter preferences. Players staying
with the same universe and texture profile reuse their existing r8 pack files;
the profile migration adds no new game-asset downloads. Changing profiles still
requires any files that are not already cached.

Additional Commando texture streaming, reduced-resolution textures and experimental
mesh changes remain private. This release does not claim a gameplay FPS improvement.
