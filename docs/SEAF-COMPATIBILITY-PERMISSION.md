# SEAF compatibility distribution

On November 5, 2026 (UTC), the project owner confirmed in this development chat
that they have written permission from both NontoxicKappa (Heavy SEAF) and
JohnnyGrease (SEAF Squad Stratagems) to distribute the Clonedivers compatibility
fixes. This records the owner's confirmation; the underlying correspondence is
not published here.

That confirmation covers the owner-tested Heavy (`1.2.0-clonedivers.3` through MP-hardened
`1.2.0-clonedivers.5`) and Squad (`0.1.4-clonedivers.2` through MP-hardened `0.1.4-clonedivers.3`)
packages. Retain their original credits, sources and notices.
It does not relicense the originals or authorize mirroring unrelated mods.
The compatible archives remain pinned by SHA-256 and `HellForge.Cli` content hash.

Other `All rights reserved` dependencies (`Smarter Guard Dogs & Sentries 5.2.0` and
`Smarter SEAF 1.0.4`) are obtained directly from their authors' GitHub Releases and are
never rehosted. Permissive `0BSD` / `MIT` dependencies (`Vanilla Plus Megapack 0.2.1`,
`Operation Reroller 0.1.6`, `Shared Callback Manager 0.1.0`, `Faster Corpse Cleanup
1.0.6-clonedivers.1`, `Dedicated Melee Slot 1.5.2-clonedivers.2`, and `Bingus Shared Loader v20`)
retain their upstream licenses and notices. Automatic host mod sharing remains off because
author packages carry mixed redistribution terms.

Pinned compatibility/gameplay downloads and content hashes are in
`Clonedivers/Resources/forge-gameplay-build25480438-r11.json`. All entries use immutable
release URLs and SHA-256 + content-hash verification; no silent upgrade to unreviewed
upstream archives or another engine is part of this preset.
