# Launcher update — candidate release notes

The launcher has a clearer primary action, more consistent Regular/Clones/Empire views, improved connection and recovery messages, and easier access to diagnostics. Verified downloads resume and retry transient failures while checking file size and SHA-256 before use.

Empire retains the published r45-v4 Full appearance and fixed enemy models. Clones/Commandos r19 and the existing gameplay preset are unchanged. Experimental Empire Lighter and enemy switches are not included. Existing preferences and receipts remain readable; an unavailable saved Empire selection requires an explicit choice of the published appearance. Switching modes alone does not erase saved appearance choices.

This update does not change LEGO trooper proportions or include r47 appearance changes. Linux gameplay and multiplayer remain unqualified. The known native-quit issue remains; use End session for the supported cleanup flow.

Candidate versions: Windows 1.14.1, Linux Forge 0.8.1, Linux Steam 0.5.0, bridge 0.4.0. Final platform scope, package/upgrade acceptance and hosted artifacts are still pending; these are not publication receipts.
