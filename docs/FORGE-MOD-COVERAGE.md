# Clonedivers Forge Mod Coverage and Pinned Preset

The `build25480438-r13` preset (`Clonedivers/Resources/forge-gameplay-build25480438-r13.json`,
integrated in Windows `2.2.0` / Linux Forge `0.11.0`) consists of three official bundled
HellForge mods, **9 required gameplay downloads** (`7,994,731` bytes / `~7.62 MiB`),
**9 optional SDK-16 defaults** (**8 client-only** `gameplay: false` + **1 host-authoritative
gameplay** `gameplay: true`, totaling `547,382` bytes), and one selected appearance pack
(`Clones 2026.11.25-r23` or `Empire 2026.11.25-r52`; Regular has none), for **22 active
mods** in Clones or Empire (`21` in Regular) when all defaults are enabled. The launcher
obtains all **18 downloads** (`8,542,113` bytes / `~8.15 MiB` total before appearance
assets) automatically on setup with archive SHA-256 verification, official `HellForge.Cli`
content-hash (`mod-hash`) checks, and atomic rollback on failure.

Because `hf-mod.com` ended public mod hosting on **19 November 2026**, `build25480438-r13`
contains **zero `hf-mod.com` URLs**:
- **4 permissive (`0BSD` / `MIT`) runtime mods** (`Vanilla Plus Megapack 0.2.1`,
  `Operation Reroller 0.1.6`, `Shared Callback Manager 0.1.0`, and SDK-16 host-gated
  `Faster Corpse Cleanup 1.0.6-clonedivers.2` + optional `Dedicated Melee Slot 1.5.2-clonedivers.3`)
  and **2 owner-permitted MP-hardened SEAF compatibility packages**
  (`Heavy SEAF Presence Everywhere 1.2.0-clonedivers.6`, `SEAF Squad Stratagems 0.1.4-clonedivers.3`)
  download from pinned GitHub Releases on `owendavidgoode/clonedivers`.
- **3 required data/loader archives** (`Bingus Shared Loader - v20`, `Smarter SEAF 1.0.4`,
  `Smarter Guard Dogs & Sentries 5.2.0`) download directly from their authors' official
  GitHub Releases (`All rights reserved` Th3chef archives are never mirrored or reuploaded).
- **8 project-owned SDK-16 mods** (`lego-compact-leaf-writer 0.2.3`, `empire-lego-yoda 0.2.2`,
  `empire-atst-writer 0.2.4`, `empire-tie-switch 0.3.2`, and `chaos-invasions 0.4.0` on
  `forge-mods-2026-11-26`; `clean-exit 0.2.1` and `starwars-localization 0.1.1` on
  `forge-mods-2026-11-25`; and `empire-camera-pullback 0.1.4` on `forge-mods-2026-11-23`)
  have full C11/C++20 source under `forge-mods/`.

See [SEAF compatibility permission](SEAF-COMPATIBILITY-PERMISSION.md) and
`Clonedivers/Resources/forge-gameplay-build25480438-r13.json` for exact sources, hashes,
versions, load order, and options.

All 9 optional defaults are enabled once on fresh `r13` setup. When upgrading from an earlier
catalog (`r4`–`r12`), enabled prior-catalog defaults upgrade automatically to their `r13`
versions (`lego-compact-leaf-writer 0.2.3`, `empire-lego-yoda 0.2.2`, `empire-atst-writer 0.2.4`,
`empire-tie-switch 0.3.2`, `dedicated-melee-slot 1.5.2-clonedivers.3`, `chaos-invasions 0.4.0`,
`clean-exit 0.2.1`, `starwars-localization 0.1.1`, `empire-camera-pullback 0.1.4`) while preserving any explicit player opt-outs or removals.
Superseded required IDs (`chef.smarter-seaf` `1.1.0`, standalone `Mod Options Menu v1.2.1`,
and `local.clonedivers-mine-boundary` `0.1.1`) are disabled automatically during setup.
