# Clonedivers Forge Mod Coverage and Pinned Preset

The `build25480438-r11` preset (`Clonedivers/Resources/forge-gameplay-build25480438-r11.json`,
integrated in Windows `2.1.4` / Linux Forge `0.10.4`) consists of three official bundled
HellForge mods, **9 required gameplay downloads** (`7,991,821` bytes / `~7.62 MiB`),
**9 optional SDK-16 defaults** (**8 client-only** `gameplay: false` + **1 host-authoritative
gameplay** `gameplay: true`, totaling `526,646` bytes), and one selected appearance pack
(`Clones 2026.11.25-r23` or `Empire 2026.11.25-r52`; Regular has none), for **22 active
mods** in Clones or Empire (`21` in Regular) when all defaults are enabled. The launcher
obtains all **18 downloads** (`8,518,467` bytes / `~8.12 MiB` total before appearance
assets) automatically on setup with archive SHA-256 verification, official `HellForge.Cli`
content-hash (`mod-hash`) checks, and atomic rollback on failure.

Because `hf-mod.com` ended public mod hosting on **19 November 2026**, `build25480438-r11`
contains **zero `hf-mod.com` URLs**:
- **4 permissive (`0BSD` / `MIT`) runtime mods** (`Vanilla Plus Megapack 0.2.1`,
  `Operation Reroller 0.1.6`, `Shared Callback Manager 0.1.0`, and SDK-16 host-gated
  `Faster Corpse Cleanup 1.0.6-clonedivers.1` + optional `Dedicated Melee Slot 1.5.2-clonedivers.2`)
  and **2 owner-permitted MP-hardened SEAF compatibility packages**
  (`Heavy SEAF Presence Everywhere 1.2.0-clonedivers.5`, `SEAF Squad Stratagems 0.1.4-clonedivers.3`)
  download from pinned GitHub Releases on `owendavidgoode/clonedivers`.
- **3 required data/loader archives** (`Bingus Shared Loader - v20`, `Smarter SEAF 1.0.4`,
  `Smarter Guard Dogs & Sentries 5.2.0`) download directly from their authors' official
  GitHub Releases (`All rights reserved` Th3chef archives are never mirrored or reuploaded).
- **8 project-owned SDK-16 mods** (`clean-exit 0.2.1` and `starwars-localization 0.1.1` on
  `forge-mods-2026-11-25`, `lego-compact-leaf-writer 0.2.2`, `empire-lego-yoda 0.2.1`,
  `empire-atst-writer 0.2.3`, `empire-camera-pullback 0.1.4`, and `chaos-invasions 0.3.5` on
  `forge-mods-2026-11-23`, plus `empire-tie-switch 0.3.0` on `forge-mods-2026-11-19`)
  have full C11 source under `forge-mods/`.

See [SEAF compatibility permission](SEAF-COMPATIBILITY-PERMISSION.md) and
`Clonedivers/Resources/forge-gameplay-build25480438-r11.json` for exact sources, hashes,
versions, load order, and options.

All 9 optional defaults are enabled once on fresh `r11` setup. When upgrading from an earlier
catalog (`r4`–`r10`), enabled prior-catalog defaults upgrade automatically to their `r11`
versions (`clean-exit 0.2.1`, `starwars-localization 0.1.1`, `lego-compact-leaf-writer 0.2.2`,
`empire-lego-yoda 0.2.1`, `empire-atst-writer 0.2.3`, `empire-camera-pullback 0.1.4`,
`chaos-invasions 0.3.5`) while preserving any explicit player opt-outs or removals.
Superseded required IDs (`chef.smarter-seaf` `1.1.0`, standalone `Mod Options Menu v1.2.1`,
and `local.clonedivers-mine-boundary` `0.1.1`) are disabled automatically during setup.
